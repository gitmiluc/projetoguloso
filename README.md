# Agenda em Python

Agenda simples de terminal para cadastrar, listar e remover compromissos.

## Como executar

```bash
python3 agenda.py
```

Os compromissos ficam salvos localmente em `eventos.json`. Esse arquivo nao e enviado ao GitHub.

Informe a data e a hora no formato `DD/MM/AAAA HH:MM`, por exemplo `25/12/2026 14:30`.
